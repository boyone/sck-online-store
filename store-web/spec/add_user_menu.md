# Add user menu

User can click user menu at header right menu.

## Create header menu user

1. Turn the user icon to component with
    - id="header-menu-user-btn"
    - type="button"
    - clickable

## user manu component behavior 

1. The Action List should hidden by default
2. When user click "header menu user btn"
3. Under the button expand list item including
    - admin(admin action list)
        - id="admin-action-list"
    - settings(settings action list)
    - sign out(sign out action list)
4. User can click "header menu user btn" to hidden the action list
5. When user click admin(admin action list) then page should navigate to product management page
